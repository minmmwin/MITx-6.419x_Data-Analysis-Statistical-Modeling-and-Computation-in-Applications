# MITx 6.419x — Data Analysis: Statistical Modeling and Computation in Applications

This repository documents my learning progress for **MITx 6.419x**, part of the MITx MicroMasters Program in Statistics and Data Science.

The course focuses on the interplay between **statistics and computation** for analyzing real-world data.

---

## 📚 Course Overview

- Institution: Massachusetts Institute of Technology (MITx)
- Platform: edX
- Status: Completed
- Focus: Statistical modeling, computational methods, and data analysis

## 🧠 Topics Covered

- Exploratory Data Analysis (EDA)
- Statistical modeling and inference
- Regression techniques
- High-dimensional data analysis
- Clustering and dimensionality reduction
- Time series analysis
- Collaborative filtering (recommendation systems)
- Reinforcement learning fundamentals
