# Analysis 4 — Time Series Analysis (CO₂ Data)

## 📌 Overview

This analysis focused on modeling and understanding time series data using real-world CO₂ concentration measurements from the Mauna Loa Observatory.

The goal was to identify long-term trends, seasonal patterns, and residual variations in the data.

---

## 🎯 Objectives

- Analyze time series data with trend and seasonality  
- Handle missing data appropriately  
- Fit regression models to time-dependent data  
- Evaluate model performance using train/test split  
- Interpret residual patterns  

---

## 📊 Dataset

- Monthly CO₂ concentration data (starting from 1958)  
- Source: Mauna Loa Observatory  
- Real-world environmental time series dataset  

---

## 🧠 Key Concepts Applied

- Time series decomposition:
  - Trend component  
  - Seasonal component  
  - Residual component  

- Linear regression modeling  
- Train/test split (80/20)  
- Handling missing values (data cleaning)  
- Model evaluation using prediction errors  

---

## 🛠️ Work Performed

- Cleaned dataset (handled missing values)  
- Converted time into numerical format for modeling  
- Split data into training and testing sets  
- Fitted linear regression model to capture trend  
- Modeled seasonal (periodic) patterns  
- Evaluated model performance on test data  
- Analyzed residuals to assess model quality
