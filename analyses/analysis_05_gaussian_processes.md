# Analysis 5 — Environmental Data and Gaussian Processes

## 📌 Overview

This analysis focused on modeling environmental ocean flow data using Gaussian Processes (GP).  
The goal was to understand spatial patterns and make predictions over a complex ocean region (Philippine Archipelago).

The dataset represents ocean current flows as a 2D vector field over time.

---

## 🎯 Objectives

- Model spatial data using Gaussian Processes  
- Understand covariance functions and kernel design  
- Predict flow values at unobserved locations  
- Analyze uncertainty in predictions  
- Work with real-world environmental data  

---

## 📊 Dataset

- Ocean flow data from the Philippine Archipelago  
- 2D grid of flow vectors (horizontal and vertical components)  
- Multiple time snapshots (time series of spatial data)  
- Grid-based spatial structure (3 km spacing)  

---

## 🧠 Key Concepts Applied

- Gaussian Processes (GP)
  - Mean function  
  - Covariance (kernel) function  

- Kernel methods:
  - RBF / squared exponential kernel  
  - Spatial correlation modeling  

- Multivariate Gaussian distributions  
- Spatial interpolation  
- Uncertainty estimation  

---

## 🛠️ Work Performed

- Loaded and processed spatial grid data  
- Combined horizontal and vertical flow components  
- Applied Gaussian Process regression  
- Designed covariance functions for spatial modeling  
- Predicted flow values at new locations  
- Visualized predictions and uncertainty  
- Evaluated model performance  

---

## 📊 Skills Demonstrated

- Gaussian Process modeling  
- Spatial data analysis  
- Kernel methods  
- Working with high-dimensional environmental data  
- Probabilistic modeling and uncertainty quantification
